# 4. KHUSUS BAB I SAMPAI BAB VII

Prioritas utama pekerjaan adalah:

**BAB I → BAB II → BAB III → BAB IV → BAB V → BAB VI → BAB VII/PENUTUP**

Untuk setiap BAB:

1. Pertahankan isi asli.
2. Terapkan format BAB dari FILE REFERENSI.
3. Terapkan style subbab dari FILE REFERENSI.
4. Rapikan spacing.
5. Rapikan alignment.
6. Rapikan indentation.
7. Pastikan setiap BAB dimulai pada halaman baru.
8. Pastikan heading tidak terpisah secara aneh dari paragraf berikutnya.
9. Pastikan tabel/gambar tidak menyebabkan layout berantakan.
10. Pastikan nomor halaman konsisten.
